# Notion 콘텐츠 스키마

기준 페이지: [다이빙투어모임](https://app.notion.com/p/41cfb09f8fa9804a8154e61409cb5d90)

이 문서는 홈페이지가 사용하는 Notion 구조와 공개 조건의 기준입니다. 데이터베이스 속성을 바꿀 때는 홈페이지 변환 코드와 이 문서를 함께 갱신합니다.

## 페이지 구조

```text
다이빙투어모임
├── 홈페이지 관리
│   └── 모임 안내 (가입 안내 포함)
├── 다이빙투어계획
├── 투어 일정
├── 회칙
├── FAQ
└── 콘텐츠 운영 안내
```

기존 `다이빙투어계획` 페이지는 콘텐츠 이관이 완료될 때까지 유지합니다.

## 투어 일정

한 레코드는 하나의 투어입니다.

Notion 데이터베이스: [투어 일정](https://app.notion.com/p/422fb09f8fa981bfa850f47dbcc11a36)

| 속성 | 형식 | 설명 |
|---|---|---|
| 투어명 | 제목 | 홈페이지 제목 |
| 슬러그 | 텍스트 | URL에 사용할 고유 값 |
| 일정 | 날짜 | 시작일과 종료일 |
| 장소 | 텍스트 | 국가, 지역 또는 수영장 |
| 다이빙숍 | 텍스트 | 이용 예정 숍 |
| 인솔 형태 | 선택 | 인솔강사, 그룹투어 |
| 인솔강사 | 텍스트 | 공개 동의를 받은 이름만 입력 |
| 제안자 | 텍스트 | 필요한 경우에만 공개 |
| 상태 | 상태 | 제안, 검토, 확정, 완료, 취소 |
| 공개 여부 | 체크박스 | 홈페이지 노출 승인 |
| 기록 공개 | 체크박스 | 완료 투어 기록 노출 승인 |
| 대표 이미지 | 파일 | 공개 가능한 이미지 |
| 최종 수정 | 최종 편집 시각 | 동기화 확인 |

서술형 일정, 준비사항과 투어 후기는 레코드 본문에 작성합니다. 사진·영상 공유 폴더는 해당 투어 본문에 암호가 설정된 MYBOX 직접 링크로 입력합니다. 암호는 카카오톡 팀 채널에서 확인하도록 안내합니다.

Notion 데이터베이스: [FAQ](https://app.notion.com/p/422fb09f8fa981a88caddabd7047d591)

| 속성 | 형식 | 설명 |
|---|---|---|

답변은 레코드 본문에 작성합니다.

## 공개 조건

투어는 `공개 여부`가 선택되어 있고 상태가 `취소`가 아닐 때 표시합니다.

완료된 투어의 본문은 `공개 여부`와 `기록 공개`가 모두 선택된 경우에만 표시합니다. 본문에 넣은 MYBOX 링크도 같은 공개 조건을 따릅니다. 링크 게시 전 암호 설정과 만료 여부를 운영진이 확인합니다.

Notion 보기 필터는 편의를 위한 것으로 접근제어 경계가 아닙니다. 빌드 코드에서 공개 조건을 다시 검사합니다.

### 일반 페이지 공개

모임 안내와 회칙은 일반 페이지여서 데이터베이스 체크박스가 없습니다. 운영진이 본문 전체의 공개를 승인하면 첫 블록에 일반 문단으로 `홈페이지 공개 승인`을 입력합니다. 빌드는 이 문단을 제외한 본문을 표시합니다. 표시가 없거나 페이지 ID가 비어 있으면 준비 안내를 표시합니다. 공개 승인 전에는 개인 이름, 연락처, 암호, 인물 사진을 검토합니다. 투어 본문의 기록과 FAQ 답변도 공개 승인 범위에 포함됩니다.

투어 본문에는 암호가 설정된 `https://mybox.naver.com/` 직접 공유 URL과 암호 확인 안내를 작성합니다. MYBOX 암호는 Notion에 입력하지 않습니다.
