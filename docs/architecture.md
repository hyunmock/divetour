# 홈페이지 아키텍처

## 목표

다이빙투어 모임의 소개, 투어 일정, 회칙, FAQ와 완료된 투어 기록을 빠르고 안전한 정적 홈페이지로 제공합니다.

## 데이터 흐름

```text
Notion
  ├─ 투어 일정
  ├─ 회칙
  ├─ FAQ
  └─ 사진·영상 메타데이터와 MYBOX URL
          ↓ 빌드 시 공개 데이터만 조회
GitHub Actions
          ↓ 검사 및 Astro 정적 빌드
GitHub Pages
          ↓ 외부 링크
네이버 MYBOX
```

MYBOX 접근 암호는 데이터 흐름에 포함하지 않습니다. 암호는 카카오톡 팀 채널에서만 공유합니다.

## 시스템별 책임

### Notion

- 홈페이지 원데이터의 단일 원본
- 콘텐츠 공개 상태와 표시 순서 관리
- 투어와 사진·영상의 관계 관리

### GitHub

- Astro와 TypeScript 소스
- 공개 가능한 이미지와 다운로드 파일
- 자동 검사와 배포 설정
- 이관 전 문서의 보관

### GitHub Pages

- 빌드 시점에 생성된 공개 정적 페이지 제공
- 사용자 인증이나 비밀정보 저장을 담당하지 않음

### 네이버 MYBOX

- 사진과 영상 원본 보관
- 공유 링크의 암호 기반 접근제어

## 공개 원칙

- 공개 승인된 Notion 항목만 빌드합니다.
- 완료된 투어의 사진·영상은 투어와 미디어 양쪽의 공개 조건을 모두 만족할 때만 표시합니다.
- Notion API 조회나 검증이 실패하면 배포를 중단하고 기존 사이트를 유지합니다.
- 정적 사이트에 비공개 데이터나 암호를 내려보낸 뒤 화면에서 숨기는 방식은 사용하지 않습니다.

## 배포 계획

Astro 정적 빌드를 GitHub Actions에서 실행하고 `https://hyunmock.github.io/divetour/`에 배포할 예정입니다. `main` 변경, 수동 실행, 정기 실행을 지원합니다. 기존 ChatGPT Site는 새 배포본 검증이 끝날 때까지 유지합니다.
